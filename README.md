# Weather Monitoring Dashboard

A weather monitoring and forecast dashboard developed as part of the CDS212 DevOps module at FH Graubünden.

## Purpose

The project demonstrates how a small web application can be developed and operated using modern DevOps practices.

The application will retrieve weather data from an external API, persist selected measurements and provide a dashboard for monitoring current and historical weather information.

The focus of the project is not only the application itself, but also the surrounding DevOps workflow, including version control, automated testing, containerization, CI/CD and deployment.

## Planned Features

- Retrieve weather data from an external API
- Display current weather conditions
- Store selected weather measurements
- Visualize historical data
- Provide a REST API
- Add automated tests
- Run the application in containers
- Build a CI/CD pipeline

## Prerequisites

- Git
- Python 3
- A Linux environment
- Internet access for retrieving weather data
